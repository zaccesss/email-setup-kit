# Gmail filters

[`filters-example.xml`](filters-example.xml) is an importable filter set. Before importing, replace:

| Placeholder | Replace with |
| --- | --- |
| `you.example` | Your personal domain |
| `you+shop` and `you+accounts` | Your own plus-addresses for shopping and sign-ups |
| `brand.example` | A brand or project domain. Copy the Brand block for each extra domain |
| `your-org` | A GitHub organisation name. Copy that filter for each organisation |

Import it under Settings, Filters and blocked addresses, Import filters. Tick **Apply new filters to
existing email** so past mail is sorted too. The [Gmail guide](../guide/03-gmail.md) explains each
group.
