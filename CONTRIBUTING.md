# Contributing

Corrections, clearer explanations, new gotchas and useful example templates are all welcome.

## What belongs here

- A guide step that is wrong or out of date because a provider changed its settings
- A gotcha you hit that is not listed yet
- An accessibility improvement to the signature builder
- A neutral, widely useful example template for the Outlook builder

## How to contribute

1. Fork the repository and create a branch named `fix/<short-description>` or
   `feat/<short-description>`.
2. Make your change. If you touched the builder or the templates, run
   `python outlook/build_oft.py` and check every template still builds.
3. Open a pull request with a clear title and a short description of what changed and why.

> [!IMPORTANT]
> Use example domains such as `example.com` in anything you add. Never include real addresses,
> booking links or other personal details.

## Reporting problems

Open an issue with what you were doing, what you expected and what happened instead.
