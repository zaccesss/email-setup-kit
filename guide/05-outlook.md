# Outlook (Microsoft 365)

These steps use Outlook on the web. The new Outlook for Mac and Windows share the same settings.

## Signatures

Settings, Account, Signatures, Add signature. Paste from the
[signature builder](../signatures/signature-builder.html), then set the defaults for new messages and
replies.

> [!WARNING]
> If Microsoft Bookings is switched on, it may offer to create a "Book time to meet with me"
> signature and make it the default. Decline it when adding your own signature with a booking link.
> Otherwise you end up with two.

To use a different signature for one email: in the compose window, open the Insert tab and choose
Signature.

## Compose settings worth changing

| Setting | Suggestion | Why |
| --- | --- | --- |
| Undo send | The maximum | Time to catch a wrong recipient |
| Reply or Reply all | Reply | Avoids replying to a whole mailing list by accident |
| Pasting from emails | Merge formatting | Pasted text takes your font instead of someone else's |
| Addresses to send from | Only your main address | Technical copies of the same mailbox look odd to recipients |

## Rules

Settings, Email, Rules, Add rule. Rules only act on new mail. Use Run rule to sort existing mail.

> [!NOTE]
> Outlook cannot import or export rules on the web, so write yours down. A few cover most of a busy
> inbox: move mail from learning platforms, careers newsletters, IT ticket systems and societies into
> their own folders. Leave mail from real people in the inbox.

## Templates

Settings, Email, Templates. A template can be pasted in by hand or imported as an `.oft` file with
Add OFT. The [Outlook builder](../outlook/) generates `.oft` files from plain text, so a set of
templates can be versioned and rebuilt in one command.

When you use a template, Outlook may also add your default signature. If the template already
contains one, delete the extra.
