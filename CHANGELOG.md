# Changelog

All notable changes are recorded here. The format follows Keep a Changelog with date based entries.

## 2026-10-03

### Added

- Guides for domains and mailboxes, deliverability, Gmail, accessible signatures, Outlook and common
  gotchas.
- An accessible signature builder with a live preview, a contrast warning and full, short and plain
  text versions.
- An importable Gmail filter set with nested labels, quiet GitHub notifications and DMARC reports
  filed away.
- A Python builder that turns plain-text templates into importable Outlook `.oft` files.
- Community files, issue forms, a pull request template and workflows that lint the markdown and
  check the templates build.
